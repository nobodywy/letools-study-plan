## 🌟 核心资料一：具身智能术语 Wiki（交互式镜像版）

- **镜像站**：https://xuheny.github.io/embodiedterms-mirror/#/
- **原站**：https://embodiedterms.com/ （内容 CC BY-NC 4.0，镜像站自动同步）

**是什么**：具身智能领域的中文术语词典，**2947 个词条、14 个分类**，每个词条包含一句话解释 / 展开说明 / 例子 / 相关词 / 来源链接，另有英文版。

**怎么用**（配合学习路线）：
- 分级浏览：「入门必知」→「入门 + 常用」→「全部」，学完概念阶段后把「入门必知」整体过一遍
- `⌘/Ctrl + K` 全局搜索，支持中文 / 英文 / 缩写，还能纠错别字
- 词条可标记「已学」（存在本地浏览器里），之后实操遇到新术语（episode、action chunking、flow matching、quantile……）随手查 + 标记
- 免登录、纯静态页面，下载仓库后双击 `index.html` 可离线使用

## 🌟 核心资料二：Qwen-RobotManip 技术报告（原文 + 知乎拆解）

- **原文**：[arXiv:2606.17846](https://arxiv.org/abs/2606.17846)（[PDF](https://arxiv.org/pdf/2606.17846)，44 页，2026-06）
- **知乎拆解**：https://zhuanlan.zhihu.com/p/2053583019710190587

**原文讲了什么**：主张 **alignment first, then scale**——先完成表示 / 运动 / 行为三层数据对齐（统一状态-动作表示、camera-frame delta EEF、in-context 策略适配），再用约 38,100 小时开源机器人数据 + 人类第一视角视频扩规模，覆盖 15 种机器人平台，不采集专有数据。

**知乎拆解覆盖**：数据工程（机器人数据 + 人类第一视角数据合成与清洗）、80 维统一动作表示、模型架构（VLM backbone + DiT action expert）、flow matching 训练、post-training、OOD 评测与消融实验。

**怎么用**（对应理论线，按顺序读）：

| 顺序 | 读的章节 |
|---|---|
| 1 | §1.1.1–1.1.2（动作数据构成） |
| 2 | §2.1（解耦架构） |
| 3 | §2.2–2.3（动作表示对齐） |
| 4 | §1 数据篇（全文最重要）+ §2 剩余 + §3 训练 |
| 5 | §4 评测与消融，「alignment first, then scale」 |

> §1 数据篇和 §4 评测篇最值得反复读。
