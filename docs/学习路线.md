### 选学 · RL 入门（具身方向）

> ACT / VLA 是模仿学习；RL 多一个奖励与试错维度。按依赖顺序走，前两步别跳。

- [ ] 价值方法：Q-learning → DQN（CartPole），吃透 Bellman、target network、replay buffer
- [ ] 策略梯度：REINFORCE → Actor-Critic → PPO（CartPole / Pendulum），重点 advantage、GAE、clip
- [ ] 连续控制：DDPG → TD3 → SAC（Pendulum / HalfCheetah），SAC 是机器人默认选择
- [ ] 离线 RL：TD3+BC → IQL → CQL（D4RL），重点理解 distribution shift
- [ ] 进阶选学：RLPD / HIL-SERL（真机 RL）、Dreamer（model-based）、GRPO / DPO（VLA 后训练）
- [ ] 资源与环境：[CS285](https://rail.eecs.berkeley.edu/deeprlcourse/) / [Spinning Up](https://spinningup.openai.com/) / [CleanRL](https://github.com/vwxyzjn/cleanrl)；Gymnasium → MuJoCo → [ManiSkill](https://maniskill.ai/) / [RoboSuite](https://robosuite.ai/)，别一上来 Isaac Lab
